# وِرد د. موفّق رحمه الله

موقع قرآن عربي (RTL) يعمل كتطبيق ويب تقدمي (PWA) على GitHub Pages، ويستعمل Supabase للحسابات واللوحة الإدارية فقط.

## النشر على GitHub Pages
1. ارفع محتويات هذا المجلد كما هي إلى جذر المستودع (ومنها `.nojekyll`).
2. Settings ← Pages ← Branch: main ← Folder: `/ (root)`.
3. كل المسارات في الشيفرة **نسبية** (`js/…`، `data/…`، `adhan/…`)، فتعمل تحت مسار فرعي مثل `/.com/`.
4. الملف الرئيسي المنشور هو **`index.html`** في الجذر. النسخ القديمة والمكررة نُقلت إلى `_archive/` ولم تُحذف (`index (1).html`، `quran-downloader (1).html`، `bg-upload.js`، المجلد القديم، ملفا zip). لا شيء منها مستعمل؛ احذف `_archive/` بعد مراجعتك لتخفيف المستودع (حوالي ١٣ ميغابايت).

## البحث عن الآيات
- يبحث في المصحف كله أو في سورة محددة، ويتجاهل التشكيل والتطويل وعلامات المصحف، ويوحّد الألف والهمزات والياء والتاء المربوطة **في نص البحث فقط**؛ الآية المعروضة هي النص العثماني الحرفي دون أي تعديل.
- يقبل نصًا عثمانيًا مُشكَّلًا ملصوقًا (مثل «الصَّلَوٰةَ»)، ومرجعًا مباشرًا مثل `2:255`. إن لم توجد العبارة متصلة يعرض الآيات التي فيها كل الكلمات.
- النتائج: نص الآية كاملًا + اسم السورة + رقم الآية + ترقيم (٢٠ نتيجة في الصفحة) + زر «فتح في المصحف» (رابط `#ayah=سورة:آية` يعمل أيضًا مباشرة).
- **المصدر**: مشروع تنزيل [tanzil.net](https://tanzil.net/docs/text_license) (Uthmani للعرض وSimple Clean للبحث)، رخصة CC BY 3.0، النسخ حرفي دون تعديل. الإسناد ظاهر في الواجهة وفي `data/quran.json`.
- **الحجم**: `data/quran.json` ٢٫١ ميغابايت خام (≈ ٤٥٠ كيلوبايت مضغوطًا من GitHub Pages). البحث محلي بالكامل (≈ ملي ثانية) ولا يرسل أي طلب أثناء الكتابة (تأخير ٣٠٠ مللي ثانية قبل التنفيذ).
- **التحديث**: `python3 tools/build-quran-data.py <uthmani.json> <simple-clean.json> <chapters.json> data/quran.json` ثم ارفع رقم `V` في `sw.js` ليُحدَّث الكاش عند المستخدمين. التحقق من الأعداد (١١٤ سورة / ٦٢٣٦ آية) مضمّن في السكربت.

## العمل دون إنترنت (PWA)
**يعمل دون إنترنت بعد أول زيارة:** الواجهة كلها، قراءة المصحف (بنص محلي)، البحث، الأذكار والتسبيح والورد وتقدمك (تُحفظ في المتصفح)، الخطوط، الأذان الافتراضي، المواقيت المحمّلة لليوم، والتلاوات التي حفظتها بنفسك.
**يحتاج إنترنت:** مواقيت يوم جديد أو مدينة جديدة (Aladhan)، البث الصوتي للتلاوات غير المحفوظة، الأذكار الصوتية (archive.org)، الحسابات واللوحة الإدارية (Supabase)، تنزيل الفيديو، قائمة القرّاء الإضافية (mp3quran).
- شريط أعلى الصفحة يوضح حالة «دون إنترنت»، ورسائل مناسبة عند تعذّر ميزة تحتاج الشبكة.
- **حفظ التلاوات**: تبويب «مقطع وتنزيل» ← «حفظ للاستماع دون إنترنت»: اختر القارئ والسورة، «احسب الحجم الفعلي» يعرض الحجم الحقيقي والمساحة المتاحة، ثم «حفظ». لا يُنزَّل شيء تلقائيًا. الحفظ في Cache API (`wird-audio-v1`) ويُلغى كاملًا عند الفشل أو امتلاء المساحة، وهناك زر حذف لكل عنصر. يدعم Range فيعمل التقديم داخل الملفات الكبيرة.
- **الكاش**: كاش القشرة `wird-shell-vN` يُحذف القديم منه تلقائيًا عند تنشيط إصدار جديد؛ كاش الصوت لا يُحذف بتحديث الإصدار. لا تُخزَّن ردود Supabase ولا أي API خارجي في الكاش.
- عند تعديل أي ملف في القشرة ارفع `V` في `sw.js`.

## الأذان
- **لا يُشغَّل أي تسجيل إلا إذا وثّقه المالك** في `adhan/registry.json` (`present:true` و`verified:true` مع `source` و`license`). غير ذلك يظهر «غير متاح» ولا يُستبدل بتسجيل آخر باسمه.
- المؤذنون (مفتاح = اسم الملف): `afasy qatami zahrani refaat minshawi abdulbasit naina makkah daghriri malki arkani hamadhani suhaib` + `malek-fajr` (بصيغة الفجر، للفجر فقط).
- **حالة هذا الإصدار**: لم يُضَف أي ملف مؤذن. تسجيلات القائمة السابقة جاءت من مستودع GitHub عام (`abodehq/Athan-MP3`) **بلا أي ترخيص**، فلم أنشرها. الأذان الافتراضي `adhan.mp3` و`adhan-fajr.mp3` (وسمه يشير إلى islamweb.net) وضعتهما أنت في المستودع، ولم أتحقق من حقوقهما: راجعهما أو استبدلهما.
- **لإضافة مؤذن**: ١) ضع `adhan/<key>.mp3` (MP3 حقيقي، اسمه مطابق للمفتاح). ٢) في `registry.json` غيّر `present` و`verified` إلى `true` واكتب `source` و`license`. ٣) `node tools/check-adhan.js`.
- أذان الفجر **خيار مستقل** («مؤذن الفجر»)؛ تسجيل الفجر الخاص لا يظهر ولا يُشغَّل في غير الفجر. يمكن اختيار «مثل المؤذن المختار».
- «تلقائي حسب القارئ» يطابق **الاسم الأول واللقب معًا** (لا لقبًا وحده)، ولا يعمل إلا إن كان تسجيل ذلك المؤذن متاحًا وموثَّقًا، وإلا يُستعمل الافتراضي مع رسالة.
- لا يبدأ الصوت تلقائيًا إلا بعد تفعيلك الأذان بموافقتك الصريحة؛ وإن منعه المتصفح يظهر تنبيه ويُرفع بأول لمسة خلال ٣ دقائق.

## الأمان (Supabase)
- ملف `staff-device-lock.sql`: **قفل الدخول الإداري (المالك والأدمن) على جهاز واحد**. يُخزَّن بصمة SHA-256 لسرّ الجهاز فقط، وكل صلاحيات اللوحة (حتى التخزين) تمر عبر `me_role()/me_can()` التي ترفض أي جهاز غير المربوط. فك الربط: زر «فك ربط الجهاز» في لوحة المالك للأدمن، وللمالك من SQL: `update staff set device=null where role='owner';`.
- حدّ المحاولات: ٥ محاولات ثم قفل ١٥ دقيقة، ثم ساعة عند ١٠، ثم ٢٤ ساعة عند ١٥، للمالك والأدمن معًا؛ العدّاد لا يُصفَّر إلا بدخول ناجح. هذا الحدّ على الجهاز؛ والحماية الخادمية الفعلية هي قفل الجهاز (من خمّن الكود من جهاز آخر لا يحصل على أي صلاحية) + **Authentication ← Rate Limits** في Supabase (فعّله).
- ترتيب تشغيل SQL: `setup.sql` ← (`fixes-review.sql` بعد قراءته) ← `staff-device-lock.sql`. تجاهل `supabase-policies.sql` (مكرر لقسم ٤ في fixes-review) و`suggestions-fix.sql` (مكرر).
- تنبيه من المراجعة: قسم ٤ في `fixes-review.sql` يحذف سياستي التخزين فيمنع غير المالك من الرفع؛ وعميل الرفع الحالي لا يكتب `list_id` فتفشل سياسة `b_add` لغير المالك. القوائم تُدار عمليًا بصفوف `@@meta`، فصلاحيات القوائم لكل أدمن تُفرض في الواجهة فقط (المالك وحده مضمون خادميًا).
- الواجهة: لا تسجيل خروج للمشرف عند انقطاع الشبكة، وتجديد الجلسة بوعد مشترك (لا سباق)، وتغيير كود المالك يتحقق من الكود الجديد قبل حذف القديم.
- `CSP`: الخطوط صارت محلية فأُزيل `fonts.googleapis.com/gstatic` منها.

## الخلفيات المحلية الاختيارية
ضع ملفات mp4/webm في `videos/` وأدرج أسماءها في `videos/list.json` (مثل `["1.mp4","غابة.mp4"]`). القائمة الفارغة تمنع طلبات 404.

## الاختبار
```bash
node tests/adhan-unit.js            # منطق الأذان: كل مؤذن، الفجر، التلقائي
node tools/check-adhan.js           # صلاحية ملفات adhan/ والتوثيق
node tools/serve.js . 8082 /.com &  # يحاكي مسار GitHub Pages الفرعي
node tests/e2e-search.js http://localhost:8082/.com/
node tests/e2e-adhan.js  http://localhost:8082/.com/ [رابط نسخة فيها ملفات حقيقية]
node tests/e2e-pwa.js    <رابط الموقع> <رابط مجلد صوت تجريبي فيه 001.mp3 على نفس الأصل>
```
تحتاج `playwright` (Chromium). اختبار «كل مؤذن يعمل فعلًا» يتطلب ملفات صوت حقيقية في نسخة اختبار منفصلة؛ لا تنشرها قبل توثيق حقوقها.
